## My Projects

### [ClarifyMed](https://github.com/roy3177/ClarifyMed) 🥈
_AI platform that transforms complex medical documents into multilingual, patient-friendly explanations._

Features:
- LLM-powered document understanding and simplification
- Text-to-Speech in multiple languages for accessibility
- Built for Israel's diverse population at AI For Life Hackathon 2026

🔗 [GitHub](https://github.com/roy3177/ClarifyMed)

---

### [Agentic Hire](https://github.com/roy3177/Agentic-hire)
_4-agent AI recruitment pipeline — live in production._

Features:
- Triage → Parser → Analyst → Team Lead agent chain
- Screens CVs against job descriptions automatically
- Returns scored, reasoned hiring recommendations

🔗 [GitHub](https://github.com/roy3177/Agentic-hire)

---

### [LevBoots Brain](https://github.com/roy3177/rag-lev-boots-project)
_RAG + MCP knowledge system — queryable by AI agents._

Features:
- Ingests PDFs, Markdown & Slack into a vector database
- Semantic search via pgvector
- Exposes an MCP server so any AI agent can plug in

🔗 [GitHub](https://github.com/roy3177/rag-lev-boots-project)
