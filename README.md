## About Me

B.Sc. Computer Science graduate, focused on building **AI-powered systems** that go from idea to production.

I design and ship **multi-agent pipelines**, **RAG systems**, **LLM-backed backends**, and **computer vision** applications — writing primarily in **Python** and **TypeScript**, from high-level LLM orchestration down to low-level C/C++.

- 🏆 **2nd Place — AI For Life Hackathon 2026** (ClarifyMed)
- 🤖 Built a **4-agent recruitment AI** (Agentic Hire) — Claude-powered, live in production
- 🧠 Built a **RAG + MCP knowledge system** (LevBoots Brain) — semantic search, pgvector, MCP server
- ☁️ **AWS Certified** — Cloud Practitioner + Developer Associate
- 🔬 Computer Vision & Image Processing — algorithms built from scratch, validated against OpenCV
